# 文案合规禁词与红线

> Amazon 会因这些内容下架 listing 甚至影响账号健康。**写完文案必须自查。**

---

## 🔴 绝对禁止

| 类别 | 禁词/句式 | 原因 |
|---|---|---|
| **认证** | FDA approved / CE certified / UL listed / BPA free（无证书时）| 虚假认证，需真实证书 |
| **医疗功效** | cure / treat / heal / prevent disease / anti-bacterial（无依据）| 医疗声明受管制 |
| **绝对化** | best / #1 / top rated / world's finest / guaranteed | 无法验证的绝对化用语 |
| **销量排名** | Best Seller / Amazon's Choice / #1 Best Seller | 只能 Amazon 官方标注 |
| **价格促销** | free shipping / 50% off / sale / cheap / $ 符号 | 促销信息不允许进标题/五点 |
| **竞品品牌** | 任何其他品牌名（如 tkptiy）| 商标侵权 |
| **保证承诺** | lifetime warranty（除非真提供）/ money back guarantee | 需可兑现 |
| **时间承诺** | ships in 24 hours（与模板不符时）| 与实际履约不符 |
| **联系方式** | 邮箱 / 电话 / 网址 / "contact us at..." | 站外引流禁止 |
| **他人商标** | 品牌名出现在标题开头以外的地方 | 需授权 |

## 🟡 谨慎使用

| 词 | 说明 |
|---|---|
| `waterproof` | 除非 IPX 等级认证，建议用 `water resistant` |
| `non-slip` | 需有实际防滑设计 |
| `heavy duty` | 可接受，但要有承重数据支撑 |
| `premium` / `professional` | 主观词，可接受但少用 |
| `eco-friendly` / `biodegradable` | 需可验证 |

## ✅ 安全写法

| 想表达 | 安全写法 |
|---|---|
| 耐用 | `reinforced stitching` / `double-stitched webbing` |
| 舒适 | `wide padded panel` / `breathable mesh` |
| 通用适配 | `fits most motorcycles` / `fits riders of most body types` |
| 好用 | `easy to reach` / `no drilling required` |
| 安全（不能暗示防护）| `gives a dedicated handhold` + **明确免责** |

---

## 必须保留的免责声明

**涉及人身安全的产品**（如本案例的扶手带）必须写明"不是安全装置"：

> Note: this is a handhold aid for a passenger, **not a safety restraint or seat belt**. Always check strap tension, buckle engagement and your passenger's reach before riding.
